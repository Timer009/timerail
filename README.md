# 微记 · timerail

把每天画成一条时间轨，做完就点亮。

在线体验：<https://timer009.github.io/timerail/>（无需注册、无需安装；手机浏览器打开后可「添加到主屏幕」当独立 App 使用，离线可开）

## 它是什么

「微记」是一款把"一天"画成竖向时间轨的记录应用：时间往下流，事项挂在对应时刻旁边，做完点一下圆圈，那段轨迹就变绿加粗。一天的进度是看得见的一段路，不是冷冰冰的百分比。

轨道之上还住着一本日记——顶部右滑就到，边写边自动保存；念头来不及成文，一条速记归进同一天。

## 功能

- **时间轨**：一天一条竖向（或横向）轨道，完成即点亮变绿；支持蛇形 / 大弧 / 直线 / 折线四种画风
- **轻记录**：点圆点加一行字就算记下，不用填开始结束时间；支持纵 / 横两种布局
- **写日记**：右滑进入，边写边存零按钮；速记（💡 灵光一闪 / 📝 温故知新 / 自定义表情）与长文归入同一天
- **全部记录**：按天折叠成卡片，关键词搜索，命中那天自动展开、字句标黄
- **顺延池**：没做完的事手动放入、次日挑时段放回，原日记录永远保留
- **日历跳转**：顶栏点日期看月历，有记录的日子带小点
- **数据自主**：只存本机 localStorage，不注册、不上传；JSON 整包导出 / 导入，文本导出

## 技术

零构建原生 HTML / CSS / ES5（单 IIFE），无框架无依赖；Service Worker 离线缓存，PWA 可安装。开发全程由 TRAE 完成需求拆解、实现与自动化自测，逐版记录见 `PROGRESS.md` 与 `HANDOFF.md`。
